Troubleshooting

My theme or page builder doesn't show the tabs

Most themes, including block themes using WooCommerce's default product template, show the tabs automatically. If your theme or builder (Elementor, Divi and others) uses its own product layout, place one of these shortcodes where the tabs should appear:

  • [bulktab_tabs] shows all tabs of the current product.
  • [bulktab_tab key="size-guide"] shows one shared tab, by its Tab ID (shown in the shared tab's sidebar).
  • [bulktab_tab slot="1"] shows one of the product's own tabs, by its number.

Add an id attribute with a product ID to show that product's tabs outside the product page.

I use a block theme with the accordion layout

With WooCommerce's default Product Details block, tabs work as in classic themes. If you switched that block to its accordion style, BulkTab's tabs are added as accordion items, but renaming, hiding or reordering the default WooCommerce sections must be done in the Site Editor.

A tab is missing on one product

Open the product, go to Product data → Tabs, and check whether the shared tab shows "Shows here by rule", and whether it is hidden on this product. Hiding wins over attaching. Empty tabs are also hidden automatically.

BulkTab says it found tab data it can't read

BulkTab names the product and leaves the data untouched rather than showing an empty tab. Email us with the product name and we'll help you look into it.

Requirements

BulkTab needs WordPress 6.8 or later, PHP 7.4 or later, and WooCommerce with the classic product editor.

What happens to my tabs if I delete the plugin?

They are kept, so reinstalling brings them back. Tab data is only removed if you first tick "Delete all BulkTab data when the plugin is deleted" under Products → Tab settings.
