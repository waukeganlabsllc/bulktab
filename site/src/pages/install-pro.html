Set up BulkTab Pro

Just bought Pro? Thank you. Freemius has emailed you a receipt with your licence key and a download link. Follow these steps to get it running.

Install and activate

  1. Install the free BulkTab plugin first. Pro adds to it, so both must be active. In WordPress, go to Plugins → Add New, search for "BulkTab", then click Install Now and Activate. You can also download it from WordPress.org.
  2. Download Pro. Open the email from Freemius and click the download link to save bulktab-pro.zip. Don't unzip it.
  3. Upload Pro. Go to Plugins → Add New → Upload Plugin, choose bulktab-pro.zip, click Install Now, then Activate.
  4. Activate your licence. Paste the licence key from the email when WordPress asks for it. If you skipped that screen, click Activate License under BulkTab Pro on the Plugins screen.
  5. Start using Pro. You'll find Products → Bulk tab tools and Products → Tab backups, and combined rules in every shared tab under Products → Shared tabs.

Pro updates then arrive on the Plugins screen like any other plugin update.

Good first steps

  • Make a backup. Under Products → Tab backups, export your tabs before your first bulk change.
  • Try a bulk change on a small group. In Products → Bulk tab tools, pick a category, check the preview, apply it, and use undo to see how it works.
  • Combine conditions. Open a shared tab and show it only where two conditions meet, such as a category and a brand.

If something doesn't work

WordPress says BulkTab Pro requires BulkTab

Install and activate the free BulkTab plugin (step one), then activate Pro again. WooCommerce must be active too.

I can't find the Freemius email

Search your inbox and spam folder for "Freemius". You can also sign in to your Freemius customer account with the email you used at checkout to download Pro and copy your licence key.

The licence key is already used on another site

A licence covers 1 site. Deactivate the licence on the old site under its Plugins screen, then activate it on the new one.
