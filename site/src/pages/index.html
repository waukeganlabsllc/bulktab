Is BulkTab really free?

Yes. Everything in the free plugin works, with no locked features, trials or licence checks. BulkTab Pro is a separate add-on for large catalogs that adds combined rules, bulk changes with undo, and backup and restore.

Will my tabs survive updates, imports and site migrations?

Yes. Each tab title and content is stored as its own plain field, so plugin and WooCommerce updates, CSV imports and search-and-replace during a migration don't corrupt them. The previous version of each product tab is kept for undo.

Does it work with my theme or page builder?

Classic and block themes show the tabs automatically. If Elementor, Divi or another builder uses its own product layout, place the [bulktab_tabs] shortcode where the tabs should appear.

Can I move my tabs from another tab plugin?

Yes. The import runs a dry run first, never changes the old plugin's data, and doesn't create duplicates if you run it again.

What do I need to run BulkTab?

WordPress 6.8 or later, PHP 7.4 or later, and WooCommerce with the classic product editor.
